# Exercise Expectations

This is a practical engineering exercise.

## Workflow

Create your own branch from `candidate/task-price-fix` and prepare it for merge to `develop`.

## Goal

Explore the codebase and improve it however you see fit.

## Guidelines

- Explain your reasoning as you go.
- If something seems off, say so and continue with a reasonable assumption.
- Using AI tools, search engines, and documentation is allowed — we want to see how you use them alongside your own judgment.
- You must be able to explain and defend every change you make.
